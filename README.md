# ⚡ CryptoDash

Criei este painel interativo para praticar a construção de dashboards modernos em *Dark Mode* e experimentar a biblioteca Chart.js na visualização de dados do mercado financeiro.

A ideia foi montar uma interface limpa, focada na experiência do usuário, onde dá para acompanhar cotações de criptos e ações de forma simples e visual.

## 🛠️ O que você encontra por aqui
- **Cards de cotações:** Preços atualizados com destaque visual para variações positivas e negativas.
- **Gráfico interativo:** Renderização de desempenho dinâmico de ativos com a biblioteca Chart.js.
- **Filtros rápidos:** Botões de alternância visual para simular diferentes períodos (24h, 7D, 1M).
- **Interface responsiva:** Visual adaptado para uma navegação fluida em qualquer tela.

---

## 🧰 Tecnologias que usei
- **HTML5 & CSS3:** Flexbox, CSS Grid e estilização customizada no tema escuro.
- **JavaScript (ES6):** Lógica da página e manipulação de eventos.
- **Chart.js:** Renderização do gráfico em Canvas.
